## 课程内容

### C11：容器与 Kubernetes，共6题

前三题围绕同一个 JDK21 订单 API、静态前端和 Redis 模型：多阶段构建/非root/SIGTERM，Compose就绪与幂等seed，容器服务名/localhost/端口。后三题逐步引入控制器与探针、配置和Secret、滚动发布/资源/RBAC边界。共享工程、分步操作、预期观察、双参考与错误实现、图示和公开JUnit桥均保留。

JUnit桥的本地策略或YAML合同通过，不代表真实Docker/Redis/Lua/kind已通过。根完整验收明确阻塞尚未接入的外部生命周期门禁。

### C12：可观测性，共3题

从安全结构化日志进入低基数指标，再到跨服务上下文。包含中文调用链、HTTP客户端、两个服务、现成前端、分步提示、公开测试及正负变体。Collector/ELK/SkyWalking等后端材料与本地HTTP合同分开。OTEL_COLLECTOR_IMAGE、JAEGER_IMAGE、PROMETHEUS_IMAGE仍缺已审台账值，不编造默认值绕过失败。

### Go：基础、快照与HTTP，共6题

greeting、quantity、order-total、snapshot逐步练习输入、整数边界、值/指针与所有权；request-lifecycle、gin-pipeline练习限制输入、错误映射、上下文取消、预算、Gin中间件顺序、Abort/Next和单次响应。Java桥会调用显式Go工具链的公开测试，不用编译失败或环境错误冒充业务负例。

公开材料含调用者、独立main、真实回环HTTP合同、双参考/分步中间态/常见错误解和图示。Go数据库/GORM后续课不在本100题范围中。

### C15：身份策略，共1题

按认证、必要属性、租户、动作和角色依次实现授权，包含完整Decision/reason和拒绝优先级。资源服务真实依赖唯一学习者Policy jar，保留类来源、重复源码、JWT/JWKS、本地HTTP最终门禁与失败传播。真实LDAP、Keycloak、联邦、SSO未完成。

### Kafka兼容修复

继承已审恢复观测修复、限定日志和所有者生命周期合同；保持PR2共享环境启动/等待修复，不把局部helper测试当作真实broker恢复验收。

### r15 本地候选：限定 AppArmor 准备、正常重启与全新验证

### r18 本地候选：明确区分活控制进程与已结束的历史证据

r17 的独立审查确认原来的控制进程/IDE 预算身份混用已经修复，同时发现一个局部缺口：已退出但尚未回收的 zombie 仍保留 PID 与出生信息，单独比较这些字段可能把它当作活 owner。无害本地进程复现了这种状态下写出合成控制记录；没有发生真实 GUI 动作或协议接受。r17 封存与失败复现继续保留。

r18 增加一个共用活 owner 检查：持有该 PID 的 pidfd，在完整原始身份/出生核对前后都确认其尚未终止。第 1–11 阶段的四种控制接收器保留等待开始时的原预算记录，读取控制响应后、写控制文件前，再核对相同记录和活身份。owner 退出、已回收、身份变化或原预算被替换时拒绝发布；900 秒绝对截止不变。post-Trust observer 的活校验复用同一检查，已完成证据的严格收集仍可在 owner 退出后进行。

新增真实无害 Python 子进程回归覆盖：保留 zombie、已回收进程、身份读取过程中退出、控制等待过程中退出、等待时预算 owner 被替换，以及退出后仍可收集原始受限回执。第 1/2/3 阶段和 Trust、插件、profile 接收器均验证了等待途中死亡不能写出控制记录。原始“实际不同出生时间的父子进程→anchor→严格采集器→第 5 阶段”组合回归再次通过。像素、PDF、窗口和输入动作仍使用夹具；这些测试没有执行真实 GUI 或安全设置操作。

最终本地回归共 **843 项 Python 测试通过**（697 项 Academy、74 项 CI、22 项公开组装、50 项 V1），文档及生成课程链接检查通过。工作流、实际课程内容/图片/锁、进程发现/清理权限、Java helper、profile 验证器和发行门禁未修改。r18 等待独立审查与发布许可；原生重跑、插件接受、profile 安装、重启和 P2 尚未执行，最终发行仍为 **BLOCKED**。

另一次范围过宽的作者测试发现命令触及未配置编译器的 Java 台账夹具，在启动 Java 前失败；原日志单独保留。它不计入上述 843 项通过结果，也没有据此申请或执行新的 Java/IDE 测试。
