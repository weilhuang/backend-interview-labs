# 一个课程入口

面向学习者只交付 **Java 后端面试实验室：完整 V1 统一课程**：一次导入包含 11 个章节、84 个任务、136 个练习区。原分课目录保留为作者维护真源，不需要逐个导入。

## 从源码生成

在仓库根安装既有 Python 检查依赖，然后执行：

```bash
python -m pip install -r scripts/quality/requirements.txt
python scripts/unify_course.py --repo . --output build/unified-course --report build/unified-generation.json
python scripts/validate_unified_course.py --course build/unified-course --repo . --report build/unified-static.json
python -m unittest discover -s scripts/tests -p test_unified_course.py -v
```

输出目录及报告必须不存在；不要把输出放进原课程、生成器模板或依赖锁输入内。重新生成时选择新的输出目录与报告名，避免覆盖学习者作答。测试默认读取 `build/unified-course`；其他输出目录通过 `UNIFIED_COURSE_ROOT` 指定。

进入生成的统一课程根：

```bash
cd build/unified-course
bash scripts/lab.sh verify
bash scripts/lab.sh doctor java
bash scripts/gradle.sh verifyCourseVersions verifyDependencyLocks
```

使用完整 JDK 21；Gradle 8.10.2 和发行依赖锁已固定。首次显式运行 `bash scripts/gradle.sh prepare --download`，或用 `prepare --zip` 指定已有官方发行ZIP；缓存必须在课程树外。没有运行时的普通命令不会自动下载，显式 LAB_GRADLE_BIN 只核版本不认证来源。默认一个 Gradle worker，默认任务只显示帮助，不启动容器。

## 按题学习与按需环境

统一根 `authoring/course-map.json` 和 `docs/题目环境映射.md` 给出所有题目的原生 Gradle 名和服务需求。执行指定题目的完整检查：

```bash
bash scripts/lab.sh check c00/01-workspace/lab
bash scripts/lab.sh check distributed-course/services/06-transactions
```

基础题不需要 Docker；真实服务题由 Testcontainers 创建隔离环境。容器题首次运行或 Docker 配置变化后先运行对应 profile 的 doctor；本地端点防护仅作用于统一 CLI，直接 Gradle/Academy Check 不继承这一检查。需要手动演示时只启动一个 profile，例如 `bash scripts/lab.sh start mysql`；不提供一次启动所有服务的默认入口。完整说明、资源预算、端口和停止方式都在统一根 `docs/统一环境.md`。

每道题仍有完整源码、调用方、公开测试和直接可读答案；源码指南、诊断材料、框架与综合项目中文前端全部随统一目录提供。重复包名按题隔离，C14 的五阶段参考源码仍独立，C10 第 06/07 题原生 Check 不降级为纯单元快测。

## Academy 导入与验收边界

普通源码生成目录不是官方课程归档。官方单 ZIP 应由固定版本的 IDEA/Academy 导出，再做干净导入、任务计数、占位、Check/Reset 与真实服务门禁。IDEA 目标为 2026.1.5，Academy 为 2026.9-2026.1-1070。

官方导出会按插件规则移除 Wrapper 程序等文件；随包 scripts/gradle.sh 从固定版本缓存启动，不要求导入重建Wrapper。也可用 IDE Check、Run 或 Gradle 工具窗口；原生验收仍是独立门禁。不能把手工压缩的源码 ZIP 叫作官方课程归档。

目前已验证统一 Gradle 模型、全源码/集成测试编译、局部参考测试和严格依赖解析。学习者局部负例中有 9 题必须由真实服务判题；Docker 和统一课程原生导出/导入仍未完成。旧分课的历史通过记录不能替代新总课验收。

维护时先改原作者真源，再运行生成器。统一依赖锁放在 `scripts/unified-dependency-locks`，统一环境模板放在 `scripts/unified-environment`；派生课程目录不重复提交维护。
