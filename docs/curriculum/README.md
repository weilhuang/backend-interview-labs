# Java 后端面试实验课程建设方案

这是一套面向「较长时间没有编码，希望恢复手感并系统准备 Java 后端面试」的完整课程建设方案。课程制作与验收优先在云端完成；学习者使用的目标 IDEA 版本为用户提供的 2026.1.5，可导入课程，重型服务可远程部署，具体学习运行方式另行选择；计划在私有仓库 `weilhuang/backend-interview-labs` 中维护多个独立课程根目录，先验证「编码恢复＋Java 集合」试点。

**本文件夹交付完整规划，不能把目录中列出的全部课程视为已经实现。** 并行制作的内部试点包位于目标仓库的 `courses/java-recovery-collections`，已有 12 个任务的源码与课程配置；它与本方案的完整 16 单元 C00/C01 目标是“先行子集与完整目标”的关系，映射见试点文档。源码存在、命令行验证、IDE 导入和可用归档是不同状态，具体实现状态以内部试点包自己的验收记录为准。本目录的编写工作没有启动基础设施或修改内部试点包代码。

## 核心决定

1. 完整课程与两周面试优先路线分开。两周决定先学什么，不决定删掉什么，也不承诺两周覆盖全部内容。
2. 共设计 16 门独立课程、113 个有明确产物和验收方式的实验单元。单元不是为了凑数量的一道填空题；实际制作时按学习闭环拆成必要的理论、编程、调试和复盘任务。
3. Java 本地可判分练习优先使用 Academy 的 Gradle、JUnit 5 和 YAML 课程模型；数据库、消息队列、Kubernetes、Istio、ELK 等采用「IDE 内讲义与代码＋外部实验环境＋证据包」混合模式。
4. 正确性、性能观察、源码理解和系统设计分别验收。不能用一个绿色 Check 冒充理解源码、证明无并发漏洞，或保证分布式一致性。
5. 用户已明确使用 JDK 21，所有 Java 课程、容器、CI、编译与测试的主基线统一为 JDK 21；Java 17/25 等只用于明确标记的版本对照。旧的 Java 17 目标试验保留为历史记录，后续必须按 JDK 21 重测。Spring Boot 3.5 与 4.x 分线。依赖的已锁值与尚未验证的运行组合分开记录，不把建议版本写成已验证事实。

## 分版交付边界

现有 12 题只是内部试点，不代表首版课程完成。V1 必须完成 Java、Java 框架、MySQL/Redis、Kafka/RocketMQ、分布式及对应综合项目，必要 Docker 支撑与预置前端同时交付；V1 无阻塞验收问题后再做 V2 云原生、可观测、企业身份工程（IAM/LDAP/Keycloak）。Go 保留完整规划，单列待排期。Spring V1 必需的认证授权基础不后移。详见[分版交付与验收矩阵](08-release-plan.md)。

## 本次明确的课程标准

- 以企业真实使用场景组织内容，由入门运行、概念、编码到源码、故障与设计逐步深入；每一步都能实际操作和验证
- 教学正文、标题、作者注释、测试说明、错误引导与标准解讲解全部中文；技术 API、命令、文件路径和原始许可证保留原名
- 每课交付完整项目、调用入口和全部可见测试，每节附可直接阅读的标准解与解释；渐进提示是辅助，不作为解答访问限制
- 用 ASCII 连接线、中文标签和具体输入输出讲机制，检查 Markdown 阅读效果，不依赖 Mermaid 渲染
- Docker 镜像统一登记复用，启动、健康检查、停止和 Testcontainers 使用同一份镜像版本来源；只按需要启用服务
- 需要界面的课程由制作方预置能工作的前端、说明如何启动和操作；每课首页列 JDK、前端、Docker/镜像依赖版本
- 面试训练包含大量有解释、有变式、有追问的问题；以独立编码、诊断和口述迁移验证能力，不把读完课程等同掌握，也不承诺面试结果

上述要求是当前制作门禁，具体可追溯检查见[需求验收清单](06-requirements-traceability.md)，面试题示范见[面试题与教学递进](07-interview-and-progression.md)。

## 学完以后需要拿得出的证据

- 能从空白或有限脚手架写出通过边界测试的实现，而非只记住答案
- 能复现失败、定位原因、修复，并保留最小回归测试
- 能沿固定版本的真实源码说明调用链、状态变化和实现边界
- 能给出数据、并发时序、日志或执行计划，解释结果及其局限
- 能在面试中按「问题与约束 → 方案 → 失败模式 → 验证 → 取舍」讲清楚一个实现

## 当前需要保留的未知项

每日可投入时间、云端环境的资源预算、IDE 实际 build number、Academy 插件安装状态、Docker 可用性及面试岗位侧重仍需核对。本方案不臆定每日小时数、不要求一开始安装整套基础设施。课程在云端做开发、兼容与资源检查，不把制作和重型实验负担转移给用户 Mac；资源不足只改变实验运行方式，不删除该主题的完整课程。

编写日期：2026-09-30。技术来源的适用版本见最后一份文档；滚动官方文档不等于已冻结的课程依赖。
