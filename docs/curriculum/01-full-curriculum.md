# Java 后端完整实验课程目录

## 如何使用这份目录

这份目录定义长期完整课程，不是两周速成删减版。每门课有独立课程根、入口诊断、可重置实验、退出标准与自己的版本清单；不要求导入一个巨大工程才能做一道题。

验收标记如下：

- **A 自动正确性**：固定输入、契约、不变量、可控时序、集成结果；适合 JUnit 或明确的外部验证器
- **O 观察与解释**：性能分布、调度、执行计划、调用链、诊断结论；提交证据并按 rubric 评阅，不能用不稳定阈值伪装自动判分
- **R 真实源码**：在已冻结源码版本定位入口、关键分支和状态；须记录 tag/commit、文件与符号
- **T 教学模型**：有意缩小的实现；必须写清省略的性质，不能称为“实现了生产级框架”

同一单元可以同时含 A、O、R、T。对照标准库只适用于已声明的同一契约；不把源码私有字段或偶然迭代顺序当公共 API。

## C00 编码手感恢复

**范围与入口**：从构建、编译、测试、断点恢复肌肉记忆；复习 Java 语义、异常、IO、泛型与常见算法。不以看完语法讲义代替编码。仅需 JVM 开发环境，不依赖 Docker；制作和测试可在云端完成。

1. **C00-01 可重复运行的工作区**。产物：一个可从 IDEA 与 Gradle Wrapper 各自执行的极小程序，修复一条失败测试并说明编译错误与断言错误的区别。A：正常、边界、异常三类测试执行；O：记录项目 SDK、Gradle JVM、测试 JVM，不把 IDE 启动 JVM当成项目 JDK。
2. **C00-02 值与对象契约**。产物：不可变 Money/OrderId、金额计算器与回归测试。A：BigDecimal 的比较/舍入约定、溢出或非法输入、null 策略、equals/hashCode 契约；O：解释对象身份、值相等、装箱和 String 不可变性。
3. **C00-03 从输入到领域模型**。产物：订单行解析器，分离解析、校验、领域规则。A：空白、坏字段、重复 ID、边界数值和错误定位；O：解释异常传播、checked/unchecked 的选择以及不吞异常的原因。
4. **C00-04 泛型与函数式转换**。产物：类型安全的 Repository 接口、Comparator 与两种订单聚合实现。A：泛型边界、稳定排序、分组结果和循环/Stream 结果一致；O：解释 PECS、惰性求值、副作用和 Optional 的合适边界。
5. **C00-05 IO 与资源生命周期**。产物：从小型文件读取订单、输出稳定报告，附失败路径。A：UTF-8、空文件、坏行、资源关闭和受控路径；O：解释 try-with-resources 与 suppressed exception，不读用户真实文件。
6. **C00-06 最小回归与调试**。产物：修复三个独立缺陷：边界索引、对象别名、异常被覆盖。A：先写能杀死缺陷的测试再修复；O：保留一份断点/变量快照与原因链，禁止只扩大超时或删断言。
7. **C00-07 面试编码模式**。产物：哈希计数、双指针/滑窗、二分边界、栈队列、树遍历、简单动态规划各一个问题的实现与复杂度说明。A：空输入、重复值、极端边界、固定种子随机小规模与暴力 oracle 对照；O：口述不变量并解释为何不用更复杂算法。各模式独立练习，避免一个巨型函数。
8. **C00-08 综合订单分析器**。产物：可独立重建的 CLI，完成导入、去重、过滤、聚合、稳定输出。A：端到端 fixture、错误输入、不依赖执行顺序；O：现场增加一个小需求并说明设计改动。作为进入 C01/C04 的诊断门槛。

**退出标准**：能不依赖答案从给定接口完成一项小功能；能读测试失败、定位到业务代码并补边界测试。语法忘记可以查文档，不能用复制整段答案替代。

## C01 Java 集合与真实 JDK 源码

**范围与入口**：集合语义、实现取舍与源码阅读一体化。教学容器只实现明确子集；JDK 源码题绑定固定版本。先修 C00-02/04/06。

1. **C01-01 集合选择与视图语义**。产物：List/Set/Map/Queue 的订单处理实现和选择说明。A：去重、顺序要求、null 策略、Arrays.asList、List.of、subList 与 unmodifiable view 的可变性差异；O：区分不可修改视图、浅不可变和深不可变。
2. **C01-02 动态数组与 ArrayList**。产物：T 的 MiniArrayList 和 R 的 ArrayList 扩容/删除路径记录。A：add/get/set/remove、越界、搬移、清除过期引用；O：增长策略与摊还成本，真实实现的延迟分配及版本边界。
3. **C01-03 链表与双端队列**。产物：T 的双向链表局部操作和用 ArrayDeque 完成 BFS/单调队列场景。A：首尾/单元素、链指针不变量、队列边界；O：解释定位成本、局部性与额外节点开销，不能说“链表插入总是 O(1)”而省略定位。
4. **C01-04 哈希契约与碰撞**。产物：正确键类型和 T 的链式 MiniHashMap。A：重复键覆盖、同 hash 不同 key、扩容迁移、null 策略、可变 key 反例；O：区别 hash 相等与 equals 相等，说明平均复杂度的假设。
5. **C01-05 真实 HashMap 路线**。产物：固定 JDK 的 put/get/resize/treeify 路线与调试证据。A：公共行为和受控碰撞案例；R/O：解释为什么某次碰撞触发扩容而非树化、树节点查找/拆分路径；阈值从目标源码读取，不把教学链表模型当树化实现。
6. **C01-06 有序映射与优先队列**。产物：TreeMap 范围查询、PriorityQueue top-K、LinkedHashMap LRU；T 可增加最小堆。A：比较器传递性、重复优先级、边界 k、更新访问顺序与淘汰；O：解释比较器与 equals 不一致、堆迭代非有序及 LRU 非线程安全边界。
7. **C01-07 迭代器与并发集合边界**。产物：安全删除修复、快照/弱一致视图对照、ConcurrentHashMap 原子复合操作示例。A：单线程结构修改的已声明行为、CopyOnWriteArrayList 快照、compute 合约；O：fail-fast 是尽力检测，不写“并发一定抛异常”的测试，复合业务操作仍需单独分析。
8. **C01-08 集合选型实验与小项目**。产物：索引式订单查询、LRU 与 top-K 综合实现，附一份 JMH 实验设计和源代码定位单。A：统一行为契约与边界；O：数据规模、读写比例、分配率、预热/fork 与结果波动。性能结论限定环境，不按“某容器必须快 X 倍”判分。

**退出标准**：集合选择有理由，能实现基础结构并明确省略内容，能在真实源码中验证一个推断。C01-07 只做并发边界入口，完整同步机制在 C02。

## C02 Java 并发与 JUC

1. **C02-01 JMM 与安全发布**。产物：可见性、原子性、有序性的最小对照和不可变对象发布案例。A：可控 lost-update 时序与修复后不变量；O：happens-before 图、volatile 不提供复合操作原子性的解释；未观察到重排不是不存在，弱内存结果用 jcstress 类工具观察而非强制出现。
2. **C02-02 线程生命周期与取消**。产物：能处理中断、超时与关闭的 worker。A：latch/barrier 控制启动、interrupt 后资源释放、join 与有界等待；O：说明中断是协作信号、恢复中断标记的情形，线程状态用快照解释。
3. **C02-03 monitor 与显式锁**。产物：有界缓冲区，分别用 synchronized/wait-notify 和 ReentrantLock/Condition 实现。A：容量不变量、while 检查条件、关闭时唤醒、异常释放；O：死锁图、公平性/吞吐取舍，不用 sleep 充当同步机制。
4. **C02-04 AQS 与同步器源码**。产物：T 的一用途同步器；R 的 ReentrantLock/AQS 获取、排队、释放路径，配 CountDownLatch/Semaphore 场景。A：教学同步器状态转换、超时/取消；O：真实队列实现与目标版本绑定，不能凭教学伪代码推断全部 AQS 特性。
5. **C02-05 CAS 与并发容器**。产物：AtomicInteger/LongAdder 对照、ABA 最小模型、ConcurrentHashMap 计数器。A：单项原子更新和最终合计、明确 ABA 修复契约；R/O：CAS 循环、竞争成本、LongAdder 的读取语义与 CHM 复合操作边界，不宣称所有无锁实现都更快。
6. **C02-06 线程池与容量保护**。产物：有界线程池配置、拒绝处理、取消清理和应用关闭。A：队列饱和后按约定拒绝、任务异常可见、无遗留线程；R/O：ThreadPoolExecutor execute/worker 路线，排队、核心线程和最大线程的交互；提交成功不等于业务成功。
7. **C02-07 CompletableFuture 与上下文**。产物：并行下游聚合，包含 deadline、部分失败、bulkhead 与 ThreadLocal 清理。A：可控调度器测试组合、异常、取消、预算；O：解释超时不自动终止底层阻塞调用、上下文传播与泄漏、common pool 风险。
8. **C02-08 虚拟线程与并发事故诊断**。产物：阻塞请求服务的传统池/虚拟线程对照，线程转储/JFR 诊断包。A：连接数/并发上限仍有效、取消与资源释放；O：吞吐/延迟/阻塞来源，版本化讨论 pinning；结构化并发等预览特性在 C03 独立隔离，不默认用于主线。

**先修**：C00/C01。**退出标准**：证明关键安全不变量、说明活性假设、能用线程转储区分 CPU 忙、锁等待和池耗尽；压力测试通过不能当形式证明。

## C03 JVM 与现代 Java

1. **C03-01 字节码与运行期语义**。产物：javap 对照、类加载/初始化顺序与双亲委派实验。A：明确程序输出及初始化触发条件；O：区分类加载器命名空间、链接、初始化，避免用含混的“加载”统称。
2. **C03-02 内存与对象生命周期**。产物：有资源上限的堆占用、引用类型和对象布局观察。A：资源关闭与业务存活范围；O：对象头、压缩指针、逃逸分析均记录 VM/架构/参数；不通过强制 GC 断言对象必须立刻回收。
3. **C03-03 GC 与停顿分析**。产物：受控分配负载、G1 与所选收集器的 GC 日志分析。A：业务结果不变与实验退出；O：分配率、堆大小、吞吐/延迟/停顿分位数、对照条件；不比较不同负载得出收集器普遍优劣。
4. **C03-04 JVM 事故工具链**。产物：CPU 热点、锁竞争、堆泄漏和线程池耗尽各一份最小事故档案。A：修复后的回归与资源释放；O：jcmd/JFR/heap dump 的证据链、保留路径与误判排除；仅对隔离实验进程生成转储。
5. **C03-05 Java 8 到 17 的语言与库**。产物：lambda/Stream、时间 API、Optional、模块边界、var、switch、record、sealed 的同一业务模型迁移对照。A：行为保持、时间/时区测试、不可变数据与模式边界；O：解释哪些是语法、库 API、JVM 变化及源/二进制兼容区别。
6. **C03-06 Java 21 的稳定能力**。产物：record pattern、pattern switch、Sequenced Collections 和虚拟线程的适用案例。A：分支覆盖、集合契约、资源约束；O：新语法没有消除的业务复杂度，与 Java 8/17 面试代码风格的兼容选择。
7. **C03-07 Java 25 与后续版本阅读法**。产物：JDK 21/25 差异报告、正式/预览/孵化/移除特性矩阵及一个隔离编译实验。A：每条特性的最低版本和编译开关经过验证；O：从 JEP、release note、migration guide 追溯，不把任何预览状态永久写死。新版本专题独立更新，不迫使全部基础课升级。

**先修**：C00；线程诊断需 C02。**退出标准**：能根据症状选择工具、解释证据不足之处，并给出可回归验证的修复，不能以调大堆替代分析。

## C04 Spring Boot 应用开发

1. **C04-01 构建与配置边界**。产物：订单 API 最小应用、配置属性与不同环境 fixture。A：参数绑定、校验、缺失配置、启动失败可解释；O：依赖管理、自动配置报告与 profile 优先级，不在教材提交密码。
2. **C04-02 HTTP 契约与输入验证**。产物：创建/查询/分页 API、统一错误响应、参数校验。A：状态码、结构、非法输入、幂等键冲突、稳定分页；O：资源模型与版本兼容、日志脱敏，区分 HTTP 幂等语义与业务去重。
3. **C04-03 持久化与事务服务**。产物：显式 SQL/JDBC 路线的订单 repository 与事务 service，可增加 ORM 对照。A：唯一约束、回滚、乐观锁或受控锁冲突；O：连接池、N+1 和事务边界，数据库规则由 C06 深入验证。
4. **C04-04 测试分层**。产物：纯单元、MVC slice、数据库集成、端到端各一层测试。A：同一缺陷被合适层检出，fixture 隔离、外部资源缺失显式报错/跳过；O：mock 能证明什么、不能证明什么，不用 H2 成功冒充 MySQL 行为。
5. **C04-05 安全与配置卫生**。产物：受保护的测试端点、最小角色策略、输入/日志处理清单。A：未认证/无权限/正常访问、错误不泄漏秘密；O：认证与授权、CSRF/CORS 的适用边界；仅使用实验身份，不制作真实凭据。
6. **C04-06 运行期治理**。产物：health/readiness、优雅关闭、超时与连接池配置、基础指标。A：停止接单与在途完成、依赖故障响应、资源归还；O：解释应用活着、服务可接流量和下游健康之间的区别。
7. **C04-07 从需求到可交付服务**。产物：完整订单服务、接口说明、部署说明和 Boot 3.5→4.x 迁移对照分支。A：契约回归、配置/依赖变更验证；O：迁移影响按所选版本说明，不能混用不同大版本 starter 与教程代码。

**先修**：C00/C01，加 C06-01 的 SQL 基础。**退出标准**：不仅跑通 CRUD，还能测试异常路径、定位事务边界、解释启动配置并安全关闭。

## C05 Spring Framework 与 Boot 真实源码

1. **C05-01 阅读路径与最小容器**。产物：T 的构造注入容器及 R 的真实 BeanFactory 入口图。A：教学容器的唯一类型匹配、缺依赖/循环依赖明确报错；O：列明未实现生命周期、scope、代理等能力，源码不靠反编译臆测版本。
2. **C05-02 Bean 定义与生命周期**。产物：R 的定义读取、实例化、属性处理、初始化、销毁调用链。A：真实容器扩展点顺序的最小测试；O：BeanFactoryPostProcessor 与 BeanPostProcessor 的执行对象/阶段，以及单例作用域的真实含义。
3. **C05-03 依赖解析与循环依赖**。产物：构造注入失败、可支持的属性注入场景和代理介入对照。A：按所选 Boot 设置记录允许/拒绝结果；R/O：解释条件与早期引用路径，不声称“三级缓存解决所有循环依赖”，不要求为教学放宽生产默认。

5. **C05-05 声明式事务的执行路径**。产物：TransactionInterceptor 至事务管理器的时间线，传播行为与 rollback rule 实验。A：外部调用/自调用、受检异常、自定义规则、REQUIRES_NEW/REQUIRED、连接释放；O：逻辑事务与物理事务、UnexpectedRollback 的原因，异步跨线程不自动继承。
6. **C05-06 MVC 请求处理链**。产物：DispatcherServlet 到 handler/argument resolver/return value/exception resolver 的源码路径。A：参数转换失败、校验失败、异常映射；R/O：过滤器、拦截器与 AOP 的边界和顺序，不凭一张流程图代替断点证据。
7. **C05-07 Boot 自动配置与条件装配**。产物：自定义轻量 starter 和条件装配测试，启动路径与自动配置候选导入源码记录。A：条件满足/缺依赖/用户覆盖时正确启退；R/O：版本化解释候选清单机制、条件报告、配置绑定及 Bean 冲突。

**先修**：C04。**退出标准**：拿一个可运行症状，从用户代码追到真实框架关键分支并修复；每条结论附版本和反例。

## C06 MySQL 索引与事务工程

1. **C06-01 数据模型与 SQL 契约**。产物：订单/明细/库存 schema、迁移、固定种子数据。A：主外键、唯一约束、金额与时区约定、join/聚合/分页结果；O：范式与冗余取舍，执行计划实验的数据分布可重建。
2. **C06-02 索引与执行计划**。产物：同一查询在索引前后的计划与数据访问对比。A：结果一致、索引定义和查询谓词正确；O：聚簇/二级索引、联合索引、覆盖、回表、排序与范围的实际计划，不断言优化器必须选某索引。
3. **C06-03 可复现的慢查询修复**。产物：深分页、函数/类型转换、选择性偏斜、join 或 N+1 中的诊断案例。A：结果/顺序保持；O：EXPLAIN ANALYZE 运行条件、估计与实际行数、冷暖缓存，测量写在报告不当绝对时间门槛。
4. **C06-04 隔离级别与 MVCC**。产物：两个真实连接的事务脚本与时间线。A：用屏障控制读写顺序，验证 RC/RR 的约定场景；O：Read View、undo、一致性读与锁定读，避免把“快照读无幻读”扩大成所有读写操作都不受影响。
5. **C06-05 锁与死锁**。产物：record/gap/next-key 的条件实验、死锁复现与安全重试。A：事务边界、锁等待超时、幂等重试、最终库存不变量；O：performance_schema 锁关系/死锁日志与索引条件，锁范围以具体版本/隔离级别/查询为准。
6. **C06-06 日志与恢复边界**。产物：redo/undo/binlog 的角色说明和隔离容器的重启恢复实验。A：在既定配置下验证已确认数据状态；O：提交、刷盘、复制与备份不是同一保证，不用一次进程重启宣称模拟了断电或证明零数据丢失。
7. **C06-07 库存并发与运维观察**。产物：条件更新/乐观锁/悲观锁对照、连接池压力和复制延迟读的案例。A：不超卖、不重复扣减、失败路径释放连接；O：吞吐与争用、读写分离的一致性取舍、备份恢复演练清单。

**先修**：C00；真实 MySQL 由混合实验启动。**退出标准**：能给出 SQL、表结构、数据分布、事务时序和计划，不靠口诀判断所有查询。

## C07 Redis 与缓存一致性

1. **C07-01 数据结构与原子命令**。产物：会话、排行榜、去重、计数器的结构选型。A：命令结果、TTL 边界、Lua 原子组合；O：String/Hash/Set/ZSet/Stream 适用面，pipeline 降低往返但不自动提供事务原子性。
2. **C07-02 过期淘汰与容量**。产物：带上限的缓存、key 大小/热点观察。A：业务过期契约与降级路径；O：主动/惰性过期、淘汰策略、big key/hot key 诊断、TTL 实际观测波动，不精确断言后台删除瞬间。
3. **C07-03 穿透击穿与雪崩**。产物：负缓存、单飞加载/互斥重建、过期抖动三种修复。A：受控并发下回源次数、失败后释放、负缓存 TTL、容量保护；O：Bloom filter 的误判与删除约束，区分三个故障的负载形态。
4. **C07-04 数据库与缓存的竞态**。产物：cache-aside 写后失效流程、确定性竞态复现、重试/版本策略。A：在声明故障模型中达到最终值与有界恢复；O：说明读写交错、删除失败、旧值回填窗口；延迟双删不是无条件强一致性证明。
5. **C07-05 持久化复制与故障转移**。产物：RDB/AOF 对照、主从/哨兵或集群最小演练。A：拓扑恢复、客户端错误处理和实验数据结果；O：确认时刻与复制/刷盘的关系、复制延迟、分片 hash slot；单节点不能证明高可用。
6. **C07-06 分布式锁与 fencing**。产物：唯一 token 获取/续租/原子解锁、过期持有者写入反例与 fencing 接收端。A：不能释放他人锁、过期 token 被资源端拒绝、取消清理；O：租约、暂停/时钟/故障假设，锁服务选择与业务可用性权衡。
7. **C07-07 缓存服务故障演练**。产物：订单读模型缓存，覆盖 Redis 不可用、慢、回源过载、恢复。A：有界连接/重试、业务不变量、可观测降级；O：命中率、延迟、回源流量、恢复拥塞，明确本地缓存和共享缓存的失效边界。

**先修**：C06 事务、C02 并发基础。**退出标准**：能画出竞态并通过实验支持结论，不用“先更新数据库再删缓存”一句话代替故障处理。

## C08 Kafka 消息可靠性

1. **C08-01 日志分区与消费契约**。产物：订单事件 producer/consumer 与可重建 topic 配置。A：key 分区、单分区顺序、consumer group 分配、offset 起点；O：扩分区与顺序/负载变化，不宣称 topic 全局有序。
2. **C08-02 生产端可靠性**。产物：acks、重试、幂等生产与超时对照。A：可控重复提交、发送失败处理、业务事件标识；O：leader/ISR/副本配置与确认边界，超时可能是结果未知。
3. **C08-03 消费提交与幂等**。产物：MySQL inbox/唯一键去重，业务提交与 offset 提交的故障注入。A：在处理前后崩溃时结果不重复且可恢复；O：at-least-once 与业务 effect-once 的条件，去重状态的保留/清理成本。
4. **C08-04 重平衡与积压**。产物：慢消费、扩缩实例、撤销分区时的处理实验。A：分区移交后不越权提交、关闭有界；O：lag、poll 预算、热点分区，所选版本的组协议单独说明。
5. **C08-05 事务与 exactly-once 边界**。产物：Kafka 内 read-process-write 事务和 abort/read_committed 对照。A：已提交/已中止事件可见性与 offset/输出原子性；O：不把 Kafka 事务扩展到任意外部数据库，外部副作用需要自己的协调。
6. **C08-06 故障恢复与设计评审**。产物：副本故障、毒消息、重放、schema 演进与 outbox 发布集成。A：已声明场景恢复与幂等、兼容旧事件；R/O：真实客户端发送或提交路径择一深入，吞吐/延迟与可靠性的取舍。

**先修**：C04/C06。**退出标准**：能用时间线解释丢失/重复窗口、重放方案与结果未知处理，不能只说“打开幂等就不会重复”。

## C09 RocketMQ 消息与事务消息

1. **C09-01 消息模型与路由**。产物：订单普通消息，显式记录 broker、NameServer、所选客户端/Proxy 模式。A：发送、消费、tag/key、消费组行为；O：4.x 与 5.x API/架构差异不混讲。

3. **C09-03 顺序与定时消息**。产物：同一业务实体顺序消费、超时订单事件。A：实体内序列、不重复取消、迟到事件处理；O：队列/分组范围、消费失败阻塞和“定时投递不等于准点执行”。
4. **C09-04 事务消息与回查**。产物：本地订单提交＋半消息确认、事务状态持久化与回查。A：提交/回滚/未知、生产者重启后回查、消费者幂等；O：事务消息协调的是本地事务与消息投递，不直接原子提交下游业务。
5. **C09-05 存储复制与故障**。产物：隔离 broker 停止/恢复、消费恢复与存储路径观察。A：规定配置与确认边界下的数据检查；R/O：CommitLog/ConsumeQueue 或所选版本等价路径，刷盘/复制不同保证，有限实验不证明所有断电场景。
6. **C09-06 Kafka 与 RocketMQ 选型对照**。产物：相同订单事件契约在两路实现，给出场景约束、成本和故障对照。A：相同业务不变量与恢复用例；O：有序、延迟、重放、事务、生态和运维取舍，不做脱离版本/负载的绝对排名。未做 Kafka 时使用提供的结果 fixture 并标明非亲测。

**先修**：C04/C06；Kafka 不是硬先修。**退出标准**：能解释回查状态依据、重复消费处理和失败窗口，能从真实消息状态诊断问题。

## C10 分布式服务与一致性

1. **C10-01 故障模型与网络基础**。产物：超时、断连、重试、乱序、重复的调用状态机。A：故障模拟器可控复现；O：TCP/HTTP/HTTP2、DNS、连接池基础，以及超时并不等于服务端未执行。CAP/PACELC 放在明确模型中讨论，不背万能口号。
2. **C10-02 gRPC 工程化**。产物：订单/库存 proto、服务与客户端、deadline/cancellation/interceptor。A：兼容消息、错误码、预算传播、取消清理、流控背压案例；O：proto 演进、HTTP/2、连接复用与 payload 取舍，禁止无限重试。
3. **C10-03 Dubbo 服务治理**。产物：同一契约的 Dubbo 服务、注册发现、负载均衡、超时和 filter。A：提供者故障、消费者预算、幂等方法重试约束；R/O：选一个真实调用链，解释注册中心与服务协议分工、配置的作用位置。
4. **C10-04 限流熔断与隔离**。产物：T 的 token bucket/滑动窗口、库实现的 breaker/bulkhead。A：可注入时钟、边界流量、半开探测、状态转换、隔离池上限；O：本地/分布式计数差异、误伤与恢复，不拿请求 sleep 模拟精准真实流量。
5. **C10-05 幂等与重试预算**。产物：业务 idempotency key、状态持久化、指数退避抖动和总预算。A：并发同键、参数冲突、处理中重入、未知结果恢复；O：键作用域/有效期和重试放大，写入幂等不意味着响应缓存永远有效。
6. **C10-06 分布式事务机制对照**。产物：2PC/XA 的受控实验、TCC 预留/确认/取消状态机、Saga 补偿序列。A：重复确认/取消、空回滚/悬挂、补偿失败重试与状态守恒；O：锁占用、可见中间态、补偿非时间倒流。生产框架适配单独记录，教学状态机不冒充 Seata 等完整实现。
7. **C10-07 Outbox 与缓存读模型**。产物：数据库事务写 outbox、可重试发布器、幂等订阅者与读模型失效。A：各 crash point 的事件不丢/可重复、去重、一致性最终收敛；O：轮询与 CDC、积压与延迟、版本冲突；定义保证成立的故障和持久化假设。
8. **C10-08 服务设计与故障预算**。产物：高并发库存设计，含容量估算、唯一 ID/分片取舍、可用性和降级矩阵。A：选定实现的不超卖/不重复核心性质；O：数据增长、热点、异地、可观测、回滚和依赖故障的设计评审；系统设计不伪装成唯一标准答案。

**先修**：C02/C04/C06/C07，事件部分选 C08 或 C09。**退出标准**：能说明每种一致性保证的作用域、前提与恢复方法，能设计并复现实质性失败路径。

5. **C12-05 从症状到根因**。产物：慢 SQL、池耗尽、重试风暴、下游慢的事故对照包。A：故障注入与修复后契约恢复；O：日志/指标/链路互证、排除替代解释、定位到具体 SQL/方法，不能把长 span 一概当 CPU 问题。
6. **C12-06 可观测性成本与复盘**。产物：数据保留、采样/基数预算、仪表盘与一页事故复盘。A：查询 fixture 与脱敏回归；O：存储/性能成本、漏报、告警到行动的 runbook，以及 agent/后端/storage 版本矩阵。

**先修**：C04、C11-01/02；链路实验需 C10 对应调用链。**退出标准**：拿到异常现象后能以证据定位并验证修复，不能只交一张正常仪表盘截图。

## C13 Go 后端基础与 Java 对照

1. **C13-01 工具链与值语义**。产物：Go module、table-driven tests、订单 parser。A：值/指针、零值、slice/map 边界、错误返回；O：与 Java 对照，解释 slice 共享底层数组和 nil 的语义。
2. **C13-02 类型接口与错误设计**。产物：小型 repository 接口、组合、泛型工具与错误链。A：interface 满足、nil interface 陷阱、errors.Is/As、包装错误；O：避免照搬 Java 类层次，泛型不替代所有接口。
3. **C13-03 goroutine 与 channel**。产物：有界 worker pool、fan-in/out 与 context 取消。A：结果完整、无 goroutine 泄漏、关闭 channel 责任、取消和背压；O：调度与 happens-before、race detector 没发现不等于无竞态。
4. **C13-04 HTTP 与数据库服务**。产物：标准库 HTTP API、SQL 事务、超时与 graceful shutdown。A：请求契约、事务回滚、context 传播、连接归还；O：连接池、middleware 边界和错误处理。
5. **C13-05 Go gRPC 与跨语言契约**。产物：与 C10 共用协议的 Go 客户端/服务。A：跨语言序列化、deadline、错误状态、兼容旧字段；O：Java/Go 的资源模型、生成代码与协议演进。
6. **C13-06 性能与运行期诊断**。产物：benchmark、pprof、竞态/泄漏诊断报告。A：修复后正确性和资源释放；O：CPU/heap/阻塞证据、逃逸/分配、基准统计；不根据单次 ns/op 结论选语言。
7. **C13-07 可交付 Go 服务**。产物：测试/格式化/静态检查/容器化的一套服务，与 Java 实现做相同契约对照。A：go test、race 可支持平台、契约和关闭路径；O：部署、可观测、错误模型与团队维护成本。

**先修**：Java 基础有助对照，Go 从零讲。**退出标准**：能写惯用 Go、处理取消与错误，不只把 Java 语法翻译成 Go。是否直接由 Academy 判分须先验证 Go authoring 支持；未验证时用同仓库原生 Go module，不伪称 Java 模板可直接承载。

## C14 后端综合项目与面试表达

1. **C14-01 需求与不变量**。产物：订单/库存/查询读模型的接口、状态机、容量假设与故障模型。A：模型检查式用例覆盖关键状态；O：明确不超卖、幂等、取消/超时的定义，排除真实支付与个人数据。
2. **C14-02 单机可靠性**。产物：Spring Boot＋MySQL 服务、Redis 缓存、唯一请求与库存约束。A：事务/并发/缓存失败下业务不变量；O：查询计划、池容量与缓存策略的依据。
3. **C14-03 异步跨服务流程**。产物：Kafka 或 RocketMQ 路线、outbox/幂等消费者、gRPC 或 Dubbo 调用。A：每个持久化边界的 crash/retry/replay 用例；O：结果未知、最终一致性和人工恢复入口，替代方案给出可比条件。
4. **C14-04 部署与事故恢复**。产物：Compose 必做、Kubernetes/Istio 对照部署，ELK/SkyWalking 排障包。A：重建、健康、故障恢复、清理；O：一次完整事故的发现→假设→验证→修复→回归证据。
5. **C14-05 盲测与面试答辩**。产物：随机挑一个故障修复、一个现场需求、一个设计问题，形成 2/5/15 分钟陈述。A：新变体测试与核心不变量；O：先讲约束、能承认未验证范围、从源码和数据支撑结论，不能把实验经历包装成生产履历。

**先修**：按选择的技术路线逐步汇合；提供干净 checkpoint 以避免前课失败阻断所有课。**退出标准**：可重建、可解释、可复现失败、可恢复，并能诚实讲清项目规模和证据。
