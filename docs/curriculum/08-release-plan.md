# 分版交付范围与验收矩阵

## 当前决定

**V1 必须把 Java、Java 框架、数据库及 Redis 缓存、消息队列和分布式做好。** V1 验收无阻塞问题后进入 V2，完成云原生、可观测和企业身份工程。Go 保留完整规划，单独等待排期，不自动取消，也不擅自归入某一版。

当前 12 题为内部试点，只用于验证教学格式、题目质量、构建、测试和 Academy 工作流。即使它们全部通过，也不能宣布 V1 完成。`0.1.0` 等代码版本号只是试点版本号，不代表本文件的正式 V1 功能范围已交付。

所有 Java 课程、容器和 CI 主基线统一为用户指定的 **JDK 21**；17 等旧版本只作为显式对照和历史验证记录。完整课程当前为 16 门、113 个单元，新增 C15 企业身份工程，不删除原有任何范围。两周路线继续独立存在，只决定学习顺序。

## 内部试点验收

- JDK21主基线、完整项目、调用方、全部可见测试、每节可读标准解/解释
- 中文正文、标题和作者注释，关键 ASCII 图解、使用示例与面试追问
- 正确解与另一种正确解通过；空实现和常见错误解被拒绝；不稳定测试查清原因
- CLI 和 Academy 预览/检查/重置/导出/重新导入分别验证
- 记录当前云端安装、依赖、IDE插件和版本实测，不把静态解析当真实运行

试点通过后可以按课程陆续提供可用内容供学习，但完整 V1 的“已完成”标签必须等下方门禁全部满足。

## V1 发布门禁

| 门禁 | 必须满足的结果 | 不可接受的替代 |
|---|---|---|
| 范围 | C00–C10和C14的V1能力闭环已完整制作 | 只有12题、只有大纲、只做Java或只做一种MQ |
| 教学 | 企业用途、概念递进、源码、编码/调用/验证、面试追问均齐备 | 只给术语、散落片段、只看视频或读答案 |
| 解答与可见性 | 每节标准解与中文解释、全项目、全部调用方与测试可直接访问 | 私有答案分支、解锁才看解答、隐藏测试补合同 |
| 环境 | JDK21、共享镜像、统一脚本、Testcontainers同源，真实服务正常启动/停止 | YAML能解析、脚本模拟通过、无Docker却宣称联调 |
| 前端 | 所需页面已由制作方做完，正常/失败/空态与真实API一致 | 占位页、假数据冒充联调、要求学员先写前端 |
| 正确性 | 正常/边界/失败恢复/并发核心不变量与负例完整验证 | 只有happy path或只看一次绿色Check |
| 源码 | 固定版本、符号与关键分支可追踪，教学模型明确标记 | JDK17记录冒充21、伪造断点截图、玩具实现当生产源码 |
| 独立能力 | 试学者能独立改需求、定位故障、口述机制与追问 | 读过或抄过标准解就标记掌握 |
| 交付 | 每门独立可导入课程、版本说明、已知问题、环境与操作文档 | 普通源码ZIP直接称Academy归档，只有作者工程能跑 |

“没问题后进入 V2”在工程上定义为：上述验收门禁全部满足，无阻塞使用、数据正确性、环境重建、题目合同或评分可靠性的未关闭问题。非阻塞排版等小项需列明影响和修复安排，不能隐瞒后宣称绝对无缺陷。

## V2 发布门禁

在 V1 门禁持续有效的基础上，增加：

- C11 完整 Docker/Kubernetes/Istio 概念、编码/配置、调用、故障诊断与清理
- C12 完整 ELK/SkyWalking，真实采集、跨服务关联、采样/基数/保留与排障
- C15 完整 IAM/LDAP/Keycloak：目录、SSO、联邦、角色/权限、服务身份、生命周期、租户隔离、审计与恢复
- 预置中文前端可完成登录、授权拒绝和身份生命周期演示；后端不信任前端按钮显示
- 新增镜像继续集中登记，版本组合真实验证，不为每课重复搭不同版本
- C14完成身份与云原生/可观测扩展，并演练跨组件故障恢复

V2 不削弱 V1 的基础认证授权，也不把基础业务安全留到最后。课堂中所有身份、目录和访问策略仅作用于隔离实验数据；真实企业目录、账户、秘密和生产权限不纳入默认教学操作。

## 能力预期与排期

这套课程用于增强实际编码、理解和表达能力，不保证任何岗位或面试结果。发布阶段是工程范围，学习阶段由基础、投入和诊断结果决定；两周学习路线不能倒过来砍掉 V1/V2 范围。

没有给 V1/V2编造完成日期。先把内部试点和环境验证做扎实，再根据实际制作/试学速度给可证实的进度。Go 待排期条目始终保留，未经用户决定不默默删除。
