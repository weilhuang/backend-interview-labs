# 教学递进与面试问答示范

## 从能运行到能解释

每门课程从企业使用场景开始，先提供可运行完整工程、调用入口、测试和标准解，再循序增加概念、实现、源码、故障与取舍。标准解始终可读；是否独立掌握，要通过新条件下的编码、诊断和口述确认。

```text
[企业问题] --> [运行现成示例] --> [解释概念与合同]
                                      |
                                      v
[新场景回测] <-- [源码与故障验证] <-- [自己编码并测试]
      |
      v
[口述机制] --> [面试追问] --> [说明限制与取舍]
```

例如库存扣减，从单线程输入校验开始，再加入数据库事务、并发条件更新、重复请求、消息重放、缓存滞后和服务超时；每次只增加一个明确条件，同时补调用示例与测试。不会因为“企业级”三个字一开始就要求部署全部中间件。

```text

  |                            |
  |--- 缓存未命中               |
```

## 64 组面试问答与追问

下面是各课统一深度的示范题，不是已经制作完所有课程的证明。每组给出回答要点与追问，正式每节还需结合自己的完整项目、标准解、源码和实测补充足量问题。避免背诵；面试模拟要求用关联实验支持答案。

### C00 编码恢复

1. **金额为什么不直接用 double？** 二进制浮点不保证十进制金额精确；内部单位、舍入、溢出规则需要明确。追问：以分存 long 后乘数量如何防溢出？实练 C00-02。
2. **输入校验应该放哪层？** 格式解析、领域约束和跨记录业务规则职责不同，错误要保留定位信息。追问：批量导入选择全部失败还是收集坏行？实练 C00-03。
3. **Stream 为什么可能难以调试？** 惰性、链式转换与副作用容易隐藏中间状态；可把纯转换拆分并对照循环。追问：parallelStream 是否总更快？实练 C00-04。
4. **如何证明修复真的有效？** 先有能复现原错误的最小测试，再修复并增加相邻边界。追问：只让现有测试绿了是否足够？实练 C00-06/08。

### C01 Java 集合

5. **equals 相等为什么要求 hash 相等？** 哈希容器先缩小候选范围，再判断相等；违反合同会破坏正常查找。追问：hash 相等是否意味着 equals 相等？实练 C01-04。
6. **ArrayList 扩容为何不使每次 add 都很贵？** 扩容成本分摊到一串追加操作，但单次仍可能搬移很多元素。追问：尾删和头删成本哪里不同？实练 C01-02。
7. **HashMap 碰撞后为什么不一定马上树化？** 实际分支还取决于容量与当前结构；要读固定版本源码。追问：改变初始容量后怎么预测执行路径？实练 C01-05。
8. **不可修改列表是否等于不可变对象？** 它可能仍是原结构的视图，元素本身也可能可变。追问：浅快照能阻止哪些变化？实练 C01-01/07。

### C02 并发与 JUC

9. **volatile 能保证 i++ 正确吗？** 它不把读改写合成一个原子操作，需按业务使用原子类或锁。追问：两个字段的不变量能用两个 AtomicInteger 解决吗？实练 C02-01/05。
10. **线程池为什么要限制队列？** 无界等待可能吞掉容量问题并放大延迟和内存，拒绝/背压必须是合同的一部分。追问：最大线程数何时发挥作用？实练 C02-06。
11. **超时为什么不等于取消成功？** 调用方停止等待不证明执行线程或远端已停止，需传播取消并设计幂等恢复。追问：阻塞 IO 不响应取消怎么办？实练 C02-02/07。
12. **虚拟线程解决了什么、没解决什么？** 它改善大量阻塞任务的线程成本，但不创造数据库连接或CPU。追问：为何仍要限流和连接池？实练 C02-08；pinning按JDK21说明。

### C03 JVM 与现代 Java

13. **类加载和初始化有什么区别？** 读取定义、链接和执行初始化属于不同阶段，触发条件不同。追问：读取编译期常量一定初始化类吗？实练 C03-01。
14. **GC 频繁就一定是内存泄漏吗？** 高分配率、堆配置和存活对象都会影响GC，泄漏需要保留链等证据。追问：如何用对照排除正常缓存？实练 C03-02/04。
15. **CPU高与响应慢怎样分辨原因？** 先看线程状态与采样，慢可能来自CPU、锁、队列、IO或下游。追问：只有长span能说明CPU热点吗？实练 C03-04。
16. **新语法是否值得直接替换旧实现？** 需要保证语义、工具链和可维护性，并区分正式与预览特性。追问：record自动提供深不可变吗？实练 C03-05/06/07。

### C04 Spring Boot 应用

17. **为什么成功启动不等于可接流量？** 初始化完成不代表关键依赖、迁移和容量就绪，readiness要表达服务能力。追问：下游短暂故障该让liveness失败吗？实练 C04-06。
18. **单元测试和数据库集成测试各证明什么？** 前者隔离逻辑，后者验证真实SQL/约束/事务；mock不能证明数据库语义。追问：H2通过能替代MySQL吗？实练 C04-04。
19. **认证与授权为何必须分开？** 确认主体是谁之后，还要判断其能否访问这条资源。追问：已登录用户换一个订单ID如何防越权？实练 C04-05。
20. **幂等API是否只是返回同一个状态码？** 关键是重试不产生额外业务效果，响应、键作用域和冲突规则也要明确。追问：同键不同参数如何处理？实练 C04-02。

### C05 Spring 真实源码

21. **BeanFactoryPostProcessor 与 BeanPostProcessor 差在哪？** 一个主要作用于定义/工厂配置阶段，一个参与实例生命周期；以真实顺序验证。追问：代理通常在哪个阶段产生？实练 C05-02。
22. **自调用为什么可能绕过事务？** 默认代理模式下，内部直接调用没有重新经过代理拦截链。追问：换成外部调用为什么生效？实练 C05-04/05。
23. **循环依赖为什么不是统一能解决？** 构造注入、早期引用、代理和配置共同决定支持边界。追问：为什么不应把开关当设计修复？实练 C05-03。
24. **自动配置为什么会退让？** 条件在特定阶段检查类/Bean/属性等；用户配置可使条件不成立。追问：如何从条件报告追到真实分支？实练 C05-07。

### C06 MySQL

25. **建了索引为何还可能全表扫描？** 优化器结合统计、选择性与访问成本决定计划，不只看索引是否存在。追问：估计行数偏差如何验证？实练 C06-02/03。
26. **MVCC 是否说明所有读取不加锁？** 一致性读与锁定读不同，版本与锁服务于不同目标。追问：RR下一条UPDATE与快照SELECT看到什么？实练 C06-04。
27. **死锁为什么不是简单加长超时？** 循环等待需要破坏等待关系或事务回滚；重试还需幂等。追问：调整更新顺序能消除所有死锁吗？实练 C06-05。
28. **redo、undo、binlog如何分工？** 恢复、版本/回滚、逻辑变更记录承担不同角色，配置影响持久化边界。追问：进程重启实验能证明断电不丢吗？实练 C06-06。

### C07 Redis

29. **穿透、击穿、雪崩如何区分？** 分别看请求不存在数据、热点失效集中回源、批量失效/不可用；保护要针对负载。追问：负缓存有什么一致性代价？实练 C07-03。
30. **先写库再删缓存为何仍有竞态？** 读取者可能在删除后回填旧值，删除失败也需要处理。追问：你能给出确定性时序吗？实练 C07-04。
31. **加锁时带token、解锁时校验为何必要？** 防止过期持有者删除新持有者的锁；检查与删除需原子。追问：这样能阻止旧持有者继续写数据库吗？实练 C07-06。
32. **pipeline 与 Lua 的保证相同吗？** pipeline主要减少往返，Lua可实现Redis内受支持操作的原子组合；都不自动协调外部DB。追问：脚本长时间执行有什么风险？实练 C07-01。

### C08 Kafka

33. **处理后提交offset还可能重复吗？** 业务已提交但offset未提交时崩溃会重放，消费方需控制业务副作用。追问：唯一键去重记录如何清理？实练 C08-03。
34. **Kafka事务能包住任意MySQL写入吗？** Kafka内事务不能自动扩展为任意外部数据库原子提交。追问：outbox解决哪个持久化边界？实练 C08-05/06。
35. **消息有序的范围是什么？** 通常按分区讨论，跨分区不天然提供全局顺序。追问：增加分区后同key路由如何变化？实练 C08-01。
36. **积压时加消费者为何可能无效？** 分区数、热点、数据库瓶颈或处理模型可能限制并行度。追问：如何从lag定位热点而不是盲扩容？实练 C08-04。

### C09 RocketMQ

37. **事务回查的状态来自哪里？** 应从可靠持久化的本地事务结果判断，不能仅看进程内变量。追问：生产者重启后怎么回答？实练 C09-04。
38. **事务消息是否使消费者本地事务原子化？** 它协调生产端本地事务与投递，消费者仍需自己的幂等与事务。追问：消费成功但确认丢了怎么办？实练 C09-02/04。
39. **顺序消息消费失败为什么要特别处理？** 贸然越过失败可能破坏业务顺序，持续阻塞又会影响可用性。追问：哪些错误进死信、谁决定继续？实练 C09-03。
40. **怎样比较Kafka与RocketMQ？** 用相同业务合同、负载、故障和运维条件比较，而不是背产品排名。追问：重放、延迟、顺序各有什么代价？实练 C09-06。

### C10 分布式

41. **远端超时之后能否直接重试扣款？** 结果可能未知，必须先有幂等标识、状态查询与受控重试预算。追问：同一请求在多个节点并发到达怎么办？实练 C10-05。
42. **限流、熔断、隔离有何区别？** 分别控制进入量、对不健康依赖快速失败、限制故障影响范围。追问：半开探测怎样避免恢复瞬间被打满？实练 C10-04。
43. **Saga补偿为何不是数据库回滚？** 已发生动作可能对外可见且不可逆，补偿是新的业务动作并可能失败。追问：怎样让补偿重试幂等？实练 C10-06。
44. **gRPC与Dubbo怎么选？** 从协议契约、跨语言、治理能力、生态与组织需求比较；具体超时/重试都要验证。追问：网关和客户端都重试会怎样？实练 C10-02/03。

### C11 云原生

45. **容器重启为何不等于恢复数据？** 容器生命周期、持久卷、数据库一致性和备份是不同层。追问：删除容器与删除卷分别影响什么？实练 C11-01/05。
46. **三种探针为什么不能照抄同一接口？** startup、readiness、liveness表达不同阶段/责任，误配可能造成重启风暴。追问：慢启动如何避免误杀？实练 C11-03。
47. **requests与limits差在哪？** 它们分别参与资源申请/调度与限制行为，具体CPU/内存症状要看事件和指标。追问：OOMKilled和CPU限流怎么区分？实练 C11-04。
48. **服务网格是否免除应用重试设计？** 网格不理解全部业务幂等，重试层叠还可能放大请求。追问：mesh与应用如何共享deadline预算？实练 C11-06/08。

### C12 可观测性

49. **日志、指标、链路为何不能互相替代？** 它们分别提供事件细节、聚合趋势和调用路径，联合使用才能排除误判。追问：追踪丢采样后怎么补证据？实练 C12-01/05。
50. **为什么不能平均多个p99？** 分位数不是可直接算术平均的聚合量，需要分布或合适的可聚合表示。追问：指标标签基数为何重要？实练 C12-03。
51. **自动探针是否保证每个异步调用都有完整链路？** 取决于插件支持、采样与上下文传播，需实际验证边界。追问：线程池切换后父span去哪了？实练 C12-04。
52. **一个告警怎样才算有用？** 要关联用户影响、可执行动作和合理窗口，避免无行动的噪声。追问：低流量错误率怎样避免误报？实练 C12-06。

### C13 Go 待排期

53. **复制slice是否复制了元素存储？** 复制描述符可能仍共享底层数组，修改和append行为需结合容量。追问：怎样获得结构独立副本？实练 C13-01。
54. **interface为何可能不等于nil？** 它可能包含动态类型与nil值；要检查包装后的语义。追问：返回typed nil error如何出错？实练 C13-02。
55. **context取消是否自动停止goroutine？** 仍需任务监听取消、退出并释放资源；通道关闭责任明确。追问：阻塞发送如何响应取消？实练 C13-03。
56. **race检测通过是否证明无并发问题？** 它依赖实际执行覆盖，未观察到不等于不存在，逻辑竞态也需业务不变量。追问：死锁与数据竞态如何分开诊断？实练 C13-06。

### C14 综合项目

57. **如何说清项目而不堆技术栈？** 从业务约束、不变量、关键取舍、故障与实测结果展开。追问：删掉一个中间件会失去什么？实练 C14-01/05。
58. **不超卖与请求都成功是否兼得？** 需要区分库存不变量、容量、竞争失败和可用性目标。追问：客户端重试会不会重复扣减？实练 C14-02。
59. **一条业务链路如何选择故障注入点？** 在每个持久化/确认/网络边界前后检查未知、重复和丢失窗口。追问：只kill一个进程有什么盲点？实练 C14-03。
60. **如何诚实表达实验经验？** 明确规模、版本、负载、亲测结果与未覆盖场景；不把教学项目包装成生产履历。追问：下一步最值得补的验证是什么？实练 C14-05。

### C15 企业身份工程

61. **LDAP与OIDC是否解决同一件事？** 目录组织/查询与身份协议/令牌职责不同，联邦可以连接二者。追问：组映射失效从哪层排查？实练 C15-02/03/05。
62. **ID token能否直接当任意API的访问凭证？** 不能混淆身份结果与资源访问授权；API须校验适用token及其签发者/受众/有效期等。追问：签名正确为何仍可能拒绝？实练 C15-03/06。
63. **员工停用后旧token会立即全部失效吗？** 取决于令牌验证、会话/撤权机制、缓存和有效期，必须定义并验证撤权窗口。追问：目录同步延迟如何处理？实练 C15-05。
64. **前端角色按钮隐藏后还需要后端授权吗？** 必须需要；客户端可自行构造请求，后端按主体、动作、租户和资源授权。追问：合法用户读另一租户订单如何拦截？实练 C15-01/08。

## 真实源码讲解的统一深度

每个核心源码主题至少讲清：用户入口、调用链关键节点、状态变量、决定行为的分支、一个失败或边界反例、为什么这样设计，以及版本变化可能在哪里。类名清单和大段复制源码都不能代替解释。

- 集合：固定 JDK21 的 ArrayList/HashMap/LinkedHashMap；先跑调用方，再看扩容、碰撞、访问顺序
- 并发：ThreadPoolExecutor、AQS/锁、ConcurrentHashMap；把API合同与内部机制联系起来
- Spring：容器生命周期、代理拦截链、事务拦截、MVC和自动配置；围绕真实症状跟踪
- 数据/MQ：服务端或客户端关键路径与真实配置/时序对应；只精读核心路径，不假称读完整仓库
- 企业身份：使用官方协议和所选Keycloak版本的关键扩展/校验入口，避免自制“生产认证框架”

每条实际源码锚点按[版本规范](05-versioning-and-sources.md)固定；本文件提供教学标准，不宣称已完成所有断点验证。

## 独立掌握的判据

任抽一道题，学习者应能给出机制和适用前提、写或修改关联实现、通过一个未见变体、诊断一个新失败，再回答至少一轮追问。只读过答案、记住术语或看见测试全绿，都不足以单独证明掌握。

课程可显著增加可练习和反馈的机会，但个人基础、投入、岗位需求和面试随机性仍影响结果；不保证“学完一定通过”或某个级别的竞争力。
