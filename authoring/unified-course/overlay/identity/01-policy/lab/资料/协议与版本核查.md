# 协议与阅读入口

以下是协议制定者与项目官方入口，供读源码和设计测试时核对。本源码草稿没有随附在线抓取快照，也未重新验证链接可访问性、镜像版本、digest或架构；不把这些链接当作已完成环境验收。

- JWT算法、issuer/audience与用途隔离：RFC8725 https://www.rfc-editor.org/rfc/rfc8725.html
- OAuth安全实践：RFC9700 https://www.rfc-editor.org/rfc/rfc9700.html
- PKCE verifier/challenge与S256：RFC7636 https://www.rfc-editor.org/rfc/rfc7636.html
- OIDC ID token与nonce：OpenID Connect Core https://openid.net/specs/openid-connect-core-1_0.html#IDTokenValidation
- LDAP filter值转义：RFC4515 https://www.rfc-editor.org/rfc/rfc4515.html
- LDAP bind与TLS服务器身份：RFC4513 https://www.rfc-editor.org/rfc/rfc4513.html
- Spring资源服务器JWT说明：https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html
- Keycloak容器说明：https://www.keycloak.org/server/containers
- Keycloak数据库兼容表：https://www.keycloak.org/server/db
- Keycloak LDAP联邦文档：https://www.keycloak.org/docs/latest/server_admin/index.html#_ldap
- OpenLDAP发布入口：https://www.openldap.org/software/download/
- 389 Directory Server容器入口：https://www.port389.org/docs/389ds/howto/howto-deploy-389ds-on-openshift.html

LDAP是协议，不等于某个服务器产品。选择镜像时必须核实发布者、准确版本、不可变digest、多架构、实际服务器包版本与安全修订。第三方镜像不能冠以上游官方身份；389DS与OpenLDAP的UUID属性、ACI和启动方式也不能混用。

课程当前固定JDK21和Spring Boot3.5.16的配置意图，最终依赖以获准环境解析、检查和提交的锁集为准。真实Keycloak/LDAP及数据库兼容性需要另外验收，本文不提供已通过结论。
