# 本节必需的 Go 语法补课

## 函数怎么读

`func SnapshotOrders(src []Order) []Order`：func 声明函数；SnapshotOrders 是名字；src 是参数名；紧跟参数名的 []Order 是参数类型；括号后 []Order 是返回类型。Go 的类型一般写在名字后面。首字母大写意味着可被其他包使用，不表示它是类的静态方法。

`dst := make([]Order, len(src))`：`:=` 在函数内声明局部变量并根据右侧推断类型。make 用于切片、map、channel。本例只创建切片；长度和容量概念不要一次与 channel 混学。

`if src == nil { return nil }`：nil 在这里表示“没有切片值引用的底层数据”。nil 切片长度是 0，但长度为 0 的切片未必是 nil。`len(src)==0` 不足以判断本题的 nil 合同。

## for range 到底给了什么

`for i, order := range src` 每次给索引 i 和该位置 Order 值的副本。在循环里只改 `order.ID` 不会改回 `src[i].ID`。但 `order.Lines[0].Quantity` 仍可能通过共享的 Lines 影响输入，所以“order 是值副本”不等于“能随便改里面”。

`for key, value := range src.Metadata` 给 map 的键和值。map 遍历顺序没有本题可依赖的保证；我们只把键值放进新的 map，不使用遍历顺序决定输出。

## 三种容器分别怎么复制

- 新订单切片：make 长度后复制 Order 值，随后继续处理内部容器
- 新标签切片：元素是 string；make 长度后 copy 字符串值即可
- 新 metadata map：make map 后逐键赋值，不存在 `copy(map, map)` 这种内建操作

`dst[i] = order` 的好处是先保留 ID 等值字段；随后把 dst[i] 的切片和 map 换成新容器。若模型新增可变字段，这一行不会自动保证深层隔离，还须扩展函数和测试。

## 与 Java 的对照只用到这里

两种语言里，变量赋值都不能自动推导出“整个对象图已复制”。但别把 Go slice 简单当成 Java List：长度、容量和 append 是否复用底层数组，是这节真正要观察的行为。内存分配在栈还是堆由具体编译器和上下文影响，本题不靠地址或 unsafe 判分。
