# Go源码阅读定位

先完成练习与测试，再阅读固定Go 1.27.1 SDK中的标准库。

- 字符串规范化：搜索strings包的TrimSpace，观察如何处理ASCII与Unicode空白
- 数量解析：搜索strconv包的Atoi和ParseInt，区分标准库允许的语法与本课更严格的数量合同
- 错误类别：搜索errors包的Is，理解它比比较错误文案更稳定的原因
- 整数上界：搜索math包的MaxInt64，手算为什么乘法与加法必须在运算前做边界检查

用`"$GO_EXECUTABLE" env GOROOT`找到本机SDK，再按符号查找文件。不要依赖会随版本变化的固定行号；本候选尚未完成标准库源码锚点核验。数量不接受正号、订单逐行首错是本实验API合同，不是所有业务接口的通用规则。
