# Go HTTP / Gin private candidate

Two additive Chinese hands-on tasks for the existing unified backend course. Start at `materials/go-http/学习路线与边界.md`.

- request-lifecycle: strict JSON body/validation boundaries, cooperative cancellation and timeout, net/http lifecycle
- gin-pipeline: route groups, explicit middleware ordering, abort semantics and consistent/redacted errors

All callers, tests, answers, starters, mutants and bridge sources are visible. Source and execution evidence are deliberately separate. See `integration/README.md` before integrating; this is not a new course root or complete Go/GORM curriculum.
