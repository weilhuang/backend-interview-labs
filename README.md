# Backend Interview Labs

面向 Java 后端开发面试的中文动手课程仓库，采用 JetBrains Academy 课程与独立基础设施实验相结合的形式。

## 项目目标

- 在 IntelliJ IDEA 2026.1.5 中验证课程体验。
- 保留完整学习范围和质量标准；面试前两周的优先练习路线与完整课程目录分开维护。
- 练习包含场景、起始代码、测试、分级提示、参考实现、源码观察和面试追问。
- 覆盖 Java、Spring / Spring Boot、MySQL / Redis、消息队列、分布式系统、云原生、可观测和 Go。

## 当前状态

仓库已初始化，课程正在制作，尚未发布可导入的学习者课程包。

第一阶段：完整课程规划、制作与验收规范，以及 Java 编码恢复和集合课程试点。

## 验证原则

仅在相应检查实际执行并通过后标记为通过。命令行测试通过不等于 IDEA 课程导入、Check、重置与导出流程已通过。普通源码 ZIP 不等于 JetBrains Academy 导出的学习者课程包。
