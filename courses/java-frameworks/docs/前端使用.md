# 预置中文前端使用

前端版本0.1.0，API版本1，原生浏览器页面。制作方已编写完整页面；学习者不需要写JavaScript或安装Node。02与07阶段提供同一界面，分别调用内存存储和真实JDBC存储。

1. 运行 `./gradlew :02-http-contract:run` 或 `./gradlew :07-integrated-service:run`，一次只启动一个
2. 在同一实验环境浏览器打开 `http://127.0.0.1:18084`
3. 保留请求编号，填SKU、数量和单价（单位分），点击提交
4. 第一次创建返回HTTP201；保持编号和内容重试返回200、同一ID
5. 保持编号但换SKU，观察409冲突；换新编号可创建新订单
6. 页面会显示HTTP状态、返回JSON和当前订单；无数据有空态，网络失败和5秒超时有解释
7. 请求期间按钮禁用，防止无意重复点击；超时不代表服务端没执行，保留编号重试确认
8. Ctrl+C停止应用；H2/内存教学数据会随实验上下文销毁，不是持久生产部署

浏览器表单会做基本输入检查；可以使用Usage/HTTP测试绕过前端，验证后端仍会拒绝非法输入。页面使用textContent展示服务响应，不把输入拼接成HTML。

## 联调检查清单

- [ ] 初始空态和加载态可读
- [ ] 成功创建、同键重试、同键冲突符合API合同
- [ ] 非法输入被后端拒绝，错误不泄漏堆栈
- [ ] 重复点击不会产生前端并行重复提交
- [ ] 后端不可用/超时显示明确消息，按钮恢复可用
- [ ] 刷新列表与服务真实状态一致
- [ ] 窄屏和键盘操作可用

HTTP测试只验证页面和API确实由服务返回，不等于浏览器操作/布局检查已通过。实际勾选状态写入阶段报告，不预先勾选。

数值精度说明：前端把单价文本交给后端精确解析，响应保留原始JSON文本展示，不先转为JavaScript浮点数再格式化，避免大整数显示失真。列表加载也有超时，并使用请求序号避免较旧响应覆盖最新刷新结果。

作者端浏览器交互检查脚本为authoring/verify_frontend.cjs，需要已有Node/Playwright/Chromium；这只是制作端验收工具，学习者运行预置页面不需要这些依赖。当前云命令沙箱拒绝Chromium的Unix socket创建，UI未执行；不得绕过限制或据此声称页面已获浏览器验收。
