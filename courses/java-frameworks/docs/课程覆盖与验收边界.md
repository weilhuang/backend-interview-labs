## 进程控制可移植性修正

停止和就绪检查已用Linux/macOS支持的ps参数与每次启动128bit随机token核对实例，不再依赖/proc，也不用全局pkill。Linux隔离回归覆盖无PID、非法PID、已退出、身份不符、主类不符、正常停止与重复停止；真实macOS启动/停止尚未实测。旧版服务没有token时新版脚本会拒绝认领，请从原启动终端结束，不要广泛杀进程。
