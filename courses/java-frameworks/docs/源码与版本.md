# 源码版本与机制边界

## 固定版本

本课实际下载并解析Spring Boot 3.5.16官方BOM，确认Spring Framework 6.2.19、Spring Security 6.5.11、JUnit5.12.2和H2 2.3.232。Testcontainers独立固定1.20.6，与全仓库一致；不使用BOM默认1.21.4。

- [Boot v3.5.16官方仓库](https://github.com/spring-projects/spring-boot/tree/v3.5.16)
- [Framework v6.2.19官方仓库](https://github.com/spring-projects/spring-framework/tree/v6.2.19)
- [Boot3.5系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)

每节task.md链接固定tag和真实文件，给出入口符号。精确commit和源文件核查证据保存在authoring/source-verification.json（产生前不得声称已存在）。IDE下载对应sources jar后应核对版本，不能把反编译或其他版本行号当原始源码。

## 阅读方法

```text
[业务调用] -> [框架公开入口] -> [关键分支] -> [状态变化]
                                     |
                                     v
                                [反例与失败路径]
```

记录运行JDK/依赖、输入、断点、状态和结论，解释为什么该分支被触发。无需复制整个框架源码；不能仅凭类名清单宣称理解。

## 教学模型限制

Tiny仅支持一个公开构造器、按类型共享实例、检测构造循环，没有Spring完整scope/代理/生命周期。02节内存幂等只保证单进程；07节JDBC依赖数据库唯一约束并明确并发冲突重试。H2验证Spring事务，但不替代MySQL隔离、锁、MVCC和恢复课程。

## Boot大版本迁移

本课运行基线为Boot3/Framework6。Boot4/Framework7迁移属于显式对照，不能把未运行的新版本写为通过。迁移检查至少覆盖：BOM/第三方兼容、starter拆分、测试包与注解、Servlet/Validation、JSON映射、配置名、自动配置候选、完整HTTP/数据库/安全回归。当前项目给出检查入口与回归合同；未单独执行Boot4兼容验证时保留“未验证”。
