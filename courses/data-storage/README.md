# V1 数据库与缓存课程

本组保留C06与C07全部14个单元，不以面试时间临近为理由压缩范围。两门各有独立Academy根，可分开导入和构建；共享同一仓库infra/versions.env镜像台账和scripts/lab.sh环境工具。

- [C06 MySQL索引与事务工程](mysql-engineering/README.md)：SQL模型、索引计划、慢查询、MVCC、锁/死锁、日志恢复、并发库存、连接池与复制延迟
- [C07 Redis与缓存一致性](redis-engineering/README.md)：数据结构、TTL/淘汰、穿透/击穿/雪崩、数据库缓存竞态、持久化复制、租约/fencing、有界故障降级

## 推荐顺序

1. C06-01建立SQL/数据模型；不会JDBC时先读其support/src与完整Usage
2. C06-02/03先看真实查询结果，再记录计划和数据分布
3. C06-04/05以确定事务时序学习MVCC、锁和失败恢复
4. C06-06/07把提交、连接资源、复制延迟与业务不变量一起验收
5. C07-01/02学习实际Redis命令与容量边界
6. C07-03/04复现回源过载与旧值回填，再实施有范围的一致性协议
7. C07-05/06理解持久化/复制/租约的故障假设和资源端fencing
8. C07-07用有界超时、回源预算和真实Redis/MySQL故障闭环收尾

## 统一证据规则

- JDK21编译与运行；完整版本在各课首页。库版本不等于镜像版本，镜像只能从唯一台账读取
- 每题完整可见源码、Usage调用端、测试、中文原理/ASCII、标准答案与面试追问
- 纯Java策略/输入测试与真实服务器集成分别标记；没有Docker时不能把纯测试通过当集成通过
- 执行计划、性能、恢复时间、锁图属于观察证据，不能用一组机器上的绝对时间阈值替代解释
- 只用合成数据、专属表/键/临时容器；不清空全局Redis、不删除用户数据库、不做Docker全局清理
- 命令行结果、Academy静态结构、IDE预览/Check/导出/导入是不同验收项，尚未执行的项目明确列出
