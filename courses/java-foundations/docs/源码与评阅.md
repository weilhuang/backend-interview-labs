# 固定源码、断点与多维评阅

OpenJDK21 GA阅读基线：tag jdk-21+35，commit 890adb6410dab4606a4f26a942aed02fb2f55387。[官方tag](https://github.com/openjdk/jdk/releases/tag/jdk-21%2B35)与[实际commit](https://github.com/openjdk/jdk/commit/890adb6410dab4606a4f26a942aed02fb2f55387)已核对。每题给出精确文件/符号、输入、关键状态和反例。本课程原创教学实现，不复制上游大段源码。

动态运行使用Temurin21.0.12.1+1，其src.zip摘要记录在HashMap实际调试.md。GA阅读结论与当前补丁二进制调试分别标记，不能说跑了补丁就等于跑了GA。没有安装或要求其他JDK。

## 证据填写模板

- 课程ID、项目/版本、tag/commit或运行包摘要
- 文件路径、类/方法符号、断点位置（行号只能辅助）
- 输入与预测；实际命令、JDK、CPU/内存上限
- 关键状态、所走分支、调用栈或原始文本证据
- 推导结论、至少一个反例、仍不能证明什么
- A自动测试结果；O/R评阅状态；使用H0至H4哪一级提示

C00调试三缺陷需要自己保留IDE断点/变量快照；尚未取得时写NOT_RUN。HashMap脚本自动取得真实JDI断点，材料在build/hashmap-trace；它不证明用户已独立会调试。

## 不混淆四个维度

| 维度 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 正确性 | 未运行 | 只有正常输入 | 边界/异常完整 | 换条件与恢复也成立 |
| 解释 | 无 | 术语复述 | 因果机制与前提 | 能用反例限定并比较替代 |
| 证据 | 无 | 只有图片 | 输入/环境/过程齐全 | 排除替代解释且可复现 |
| 迁移 | 复制 | 大量提示 | 少量提示独立完成 | 不看答案改条件并补测试 |

完成要求：所有关键A通过，其他维度至少2；资源泄漏、金额错误、数据丢失核心缺陷未解决则不能通过。H0-H4是学习轨迹，不是人格或招聘评分。24小时后换条件独立回测，不能“看过答案”即标掌握。

## 真实实现与教学模型

MiniArrayList只包含add/get/set/remove和可见诊断接口；MiniHashMap只有拉链；双向链表不暴露节点、不实现List完整合同；LRU/IndexedOrders非线程安全；内存Repository不是数据库事务。真实HashMap源码的树化、拆分、比较分支另做R任务，不能从教学类推断全部JDK特性。
