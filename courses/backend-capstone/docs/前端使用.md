# 已预置的中文前端

页面由Spring Boot静态资源服务提供，没有CDN、前端打包或模拟业务数据。学员只改本节后端学习区；GET/POST都调用本项目真实接口。

页面包含请求号、商品和数量表单、原号重试、强一致/缓存查询、库存与积压计数、四依赖健康、订单取消、配送投影、错误信息、审计和操作记录。默认不定时刷新，用户可开10秒刷新；加载页面只读，不提交订单。35秒客户端超时显示“结果未知”，保留请求号供查询。

演示正常路径后，保留原请求号改数量验证409；暂停delivery后重放，页面应显示依赖失败；恢复并重放，再检查投影。没有静态伪造的健康徽章。接口内容用textContent创建，避免订单号被当作HTML执行。

作者浏览器验收脚本使用固定Playwright1.62.1、runner已安装Chrome且启用Chromium沙箱。每个动作10秒、导航15秒、重放等待40秒、总预算180秒；失败打印阶段并保存截图。浏览器测试需要真实Compose已启动，静态语法检查不能替代联调通过。
