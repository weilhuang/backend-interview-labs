# 已预置的中文前端

页面由Spring Boot静态资源服务提供，没有CDN、前端打包或模拟业务数据。学员只改本节后端学习区；GET/POST都调用本项目真实接口。

页面包含请求号、商品和数量表单、原号重试、强一致/缓存查询、库存与积压计数、四依赖健康、订单取消、配送投影、错误信息、审计和操作记录。默认不定时刷新，用户可开10秒刷新；加载页面只读，不提交订单。35秒客户端超时显示“结果未知”，保留请求号供查询。

演示正常路径后，保留原请求号改数量验证409；暂停delivery后重放，页面应显示依赖失败；恢复并重放，再检查投影。没有静态伪造的健康徽章。接口内容用textContent创建，避免订单号被当作HTML执行。

手机布局采用可收缩的网格列；订单和配送表格保留完整字段，在各自容器内横向滚动，不把整页撑宽或裁掉末列。触屏左右滑动表格，键盘用户可Tab聚焦表格后用方向键查看。长请求号、库存商品号和诊断文字在非表格区域可换行。

作者浏览器验收脚本使用固定Playwright1.62.1、runner已安装Chrome且启用Chromium沙箱。每个动作10秒、导航15秒、重放等待40秒、总预算180秒；失败打印阶段并保存截图。使用合同允许的64字符请求号，实走提交、原号重试、冲突、取消和Kafka/gRPC重放；之后在320、390、800、801、1440像素视口检查页面与外层容器没有横向溢出，窄屏表格确实可以局部滚动到最后一列。各视口尺寸与滚动证据保存在build/browser-layout.json，截图随CI artifact保存。

浏览器测试需要真实Compose已启动，静态语法检查不能替代联调通过。2026-09-30的CI 36740557113真实业务操作已通过，但390像素布局断言失败；本次CSS修复及增强门禁须以新提交的CI结果为准。
