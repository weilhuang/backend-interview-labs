# 固定源码与版本核验

课程JDK21源码阅读基线OpenJDK jdk-21+35，commit `890adb6410dab4606a4f26a942aed02fb2f55387`；运行补丁按阶段报告。Gradle8.10.2，Wrapper来自官方JetBrains模板commit `c23b40acc8e1a0628e036598935ee6139cca0077`，wrapper JAR SHA-256 `a8451eeda314d0568b5340498b36edf147a8f0d692c5ff58082d477abe9146e4`，Gradle发行包SHA `31c55713e40233a8303827ceb42ca48a47267a0ad4bab9177123121e71524c26`。

Spring Boot固定v3.5.16，Spring Framework由BOM锁定6.2.19。Kafka client显式strictly3.9.1、Jedis5.2.0、MySQL驱动9.2.0、protobuf4.29.0，避免BOM悄悄选用另一版本。gRPC与生成插件为1.71.0。Testcontainers BOM为enforced1.20.6。真实解析后的依赖锁随课程提供，升级须重新验证。作者同时核对Maven Central发布的.module元数据，保留Jackson BOM 2.21.4节点、JVM对应的Guava jre变体和明确测试运行依赖；不以忽略.module或关闭锁定解决差异。

每节task.md有准确符号、固定版本链接、输入和断点任务。MySQL官方手册链接为8.4系列，不能把页面文字当作对应容器补丁源码断点。数据库实验应同时记录共享镜像台账中的具体8.4.7版本。

协议是本课程自有delivery.proto，借鉴同仓库C10的“固定protobuf生成器＋公开协议”的组织方式，没有直接依赖C10源码目录。使用protoc4.29.0和protoc-gen-grpc-java1.71.0生成完整Java协议类；这些工具生成的英文注释保留原样以保证可再生，作者叙述与手写注释为中文。

重新生成命令：

```bash
protoc --proto_path=protocol --java_out=app/src/main/java \
  --plugin=protoc-gen-grpc-java=/固定路径/protoc-gen-grpc-java \
  --grpc-java_out=app/src/main/java protocol/delivery.proto
```

这一步属于作者维护，学员无需安装生成器或修改前端。不要因为依赖已解析就推断服务兼容；以实际集成与浏览器记录为准。
