# 并发实验的证据模板

每单元复制以下模板，保存为自己的学习记录。字段完整不等于结论正确。

## 环境与状态
- 单元、日期、操作系统/架构
- java -version、JVM参数、Gradle版本、IDE/Academy版本
- 源码：OpenJDK21 GA / jdk-21+35 / 890adb6410dab4606a4f26a942aed02fb2f55387
- 自动A：PASS / FAIL / BLOCKED / NOT_RUN；命令、测试数与日志路径
- 原始源码静态R：已阅读符号与路径；动态断点R：实际运行版本/未运行
- 观察O：有效样本/环境无效/未运行；不与A合并成绿色

## 机制与可复现输入
1. 用两三句写业务合同与安全不变量
2. 画ASCII状态图，标记happens-before、线性化点、资源获取/释放
3. 给最小输入和线程协调顺序；等待必须有上限
4. 预期与实测分别记录；没有出现的现象不能证明永远不会发生

## 源码路线
- 入口类/方法
- 判定分支、状态值、队列/线程状态
- 下一跳符号
- 取消/失败路径
- 教学模型省略了什么
- 源码与当前JDK补丁的差别或尚未核验部分

## 故障/性能观察
- 症状、候选原因、最小复现
- 线程栈/JFR/日志证据：时间、对象/线程/事件对应关系
- 至少一个替代解释以及排除依据
- 修复、回归测试、残余风险
- 性能对照记录相同负载、线程数、堆、预热、fork、样本量、分布；不把单次耗时当普遍结论

## 口述与迁移
- 机制、边界、取舍、追问各一段
- 新变体与新增测试
- 提示H0–H4、首次用时、24小时回测
- 仍未理解或仍未验证的项

## 人工评阅
每项0–3分：机制说明、证据质量、边界辨识、独立迁移。至少2分才算完成；只背术语/贴截图/读取标准解不得直接记3分。
