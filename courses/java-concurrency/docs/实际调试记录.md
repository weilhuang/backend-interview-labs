## 可以据此得出的结论

- 业务入口OneShotGate.open确实进入JDK的releaseShared，而不是教材模拟一个同名函数
- releaseShared入口时状态为0，对应门还未打开；后续tryReleaseShared负责0→1转换
- 两个工作者最终通过门，顺序受单许可Semaphore约束，完成latch最终放行主线程
- 实际二进制中的行号1180与GA源码中该符号行号可能不同，说明版本必须拆开记录

## 这份证据没有证明什么

它没有记录每一种AQS竞争交错、取消节点清扫、所有CPU内存行为或公平性，也不是IDEA截图。进程顺利退出不能单独证明所有实现都无死锁。其余源码路径仍按各节要求独立提交动态证据，不从这一个调用栈外推整门课都做过断点。
