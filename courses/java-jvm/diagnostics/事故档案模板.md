## 安全与清理

每次脚本只启动自己的子进程，12秒主动退出、24秒看门狗，不接受用户外部PID；堆96MiB、CPU仅一个忙工作线程并定期让出。heap dump默认关闭，仅retention加--heap生成合成快照。不要把jcmd指向生产或用户现有进程。保留所需证据后仅删除本次build/evidence/incident-模式-时间目录，课程不自动清空其他文件。

## 一份可用结论需要什么

CPU：连续时间窗中的执行采样与热点路径，而非一个RUNNABLE截图。锁：同一监视器owner/waiter关联，解释为何不是循环死锁。保留：业务寿命已结束仍从root可达，直方图单独不足。池：工作线程在等什么、队列/拒绝与上游延迟的因果链，不能用加线程替代下游预算。
