## 不靠源码私有细节猜合同

[JVM规范21第5章](https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-5.html)定义加载、链接、初始化语义；[JLS21第12章](https://docs.oracle.com/javase/specs/jls/se21/html/jls-12.html)说明初始化触发。API合同与某实现分支分开记录。

[Java21 jcmd官方说明](https://docs.oracle.com/en/java/javase/21/docs/specs/man/jcmd.html)、[JFR工具](https://docs.oracle.com/en/java/javase/21/docs/specs/man/jfr.html)供诊断命令复核。GC.class_histogram可能触发GC、堆转储可能停顿，采集行为本身会扰动被测进程。
